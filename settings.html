Lead Statuses
Drag to reorder. Represents a contact's current relationship to your company.
This is a real hierarchy, lowest at top to highest at bottom -- not just display order. Anything the app sets automatically (a form with a booking step, a new booking) can only move a contact FORWARD through this list, never backward: a BLACKLIST contact re-submitting a form stays BLACKLIST, an ENROLLED contact who mistakenly books another call stays ENROLLED. Opt Out
Automatic opt-out rules, so no one keeps getting texted or emailed after they've asked to stop.
When a reply's ENTIRE text is one of these words (not just mentioned in a sentence), SMS is opted out for that contact. Their pipeline status (ENROLLED, BOOKED, etc.) is never touched by this — someone can still very much be an active student and just want texts to stop, so status stays whatever a human set it to. This never affects email — email opt-out only happens via an explicit unsubscribe link click.
When a contact's status is set to STOP, SMS is opted out. When set to Blacklist, both SMS and email are opted out and the conversation is hidden from the Inbox's default view (visible under the Hidden filter, no unread alerts). Applies no matter how the status was changed (manually, or automatically above).
If a reply CONTAINS any of these words anywhere in it (not just as the entire message), the contact's status is set to Blacklist -- both SMS and email opted out, conversation hidden. Permanent: no reverse trigger.
Website & Page-Visit Tracking
Lets automations and SMS workflows trigger off a contact visiting a page on your site (Framer), after they've clicked a tracked email link.
Embed on your site
Paste this into a custom code / embed block on every page (e.g. Framer's Site Settings → Custom Code → End of <body> tag) you want page-visit triggers to work on. The full script is inlined here (not just a <script src> reference) so it works even where an external script tag wouldn't load reliably.
Ad Platform Link Tracking
Reference values for attributing traffic back to a specific ad. Meta and Google append these to your landing page URL when someone clicks an ad.
Paste into Meta Ads Manager → Ad Set → Tracking → URL Parameters.
Paste into Google Ads → Settings → Account-level (or Campaign-level) Tracking Template.
CRM Email/SMS Link Tagging
Nothing to configure here -- every link this CRM sends in email or SMS is automatically tagged ?el=email-<campaign-or-automation-name> or ?el=sms-<workflow-name>, matching the el= convention already used on your ads, social posts, and YouTube links.
Conversion Tracking (Meta & Google Ads)
Pushes real conversions (lead, booking, sale...) back to Meta and Google so their ad algorithms can optimize toward them -- matched by hashed email/phone, no click id needed. This is what Hyros used to do.
Meta
Same access token also powers "Add to Custom Audience" automation steps -- needs the ads_management permission, not just Conversions API access.
Google Ads
Reuses this app's existing Google OAuth client. Need a refresh token with Ads API access? Run node get_ads_token.js from the project folder and paste the result here.
Conversion Events
Define the events worth tracking. Nothing fires automatically -- wire each one into a Flow with a "Send Conversion Event" step wherever it actually happens (form submitted, booking created, status changed, etc).
Send Test Event
Fires against both platforms regardless of the event's own toggles, so you can check the connection before wiring anything real.
